# Altarious Global — website

Premium PPC / lead generation / inbound calls / live transfers website built to the PRD in `docs/PRD-source.txt`.

- **Stack:** static HTML generated by a dependency-free Node script, Cloudflare Pages Functions for forms and admin, Cloudflare D1 for inquiries and CMS content. Everything on the Cloudflare free tier. No npm packages.
- **Content model:** Vertical → Sub-Vertical → Product (Inbound Calls / Live Transfers) → ≥2 knowledge articles, all managed in the admin UI at `/admin`.
- **Launch content:** 3 verticals, 35 sub-verticals, 70 product pages, 140 articles, 370 pages total.

| Doc | What |
|---|---|
| `DEPLOY.md` | Step-by-step Cloudflare Pages + D1 deployment, env vars, custom domain (Spaceship → Cloudflare DNS) |
| `docs/PLAN.md` | Build plan, decisions, acceptance mapping |
| `docs/ARCHITECTURE.md` | Folder layout, request flow, URL scheme, env vars |
| `docs/CONTENT-MODEL.md` | JSON shapes for every content entity |

## Quick start
```bash
node scripts/build.mjs      # build dist/
npm run db:local            # once: create local D1 tables
npm run dev                 # http://localhost:8788  (admin: /admin, password admin123)
```
In the admin, click **Import seed content** on first run, then edit and **Publish site**.
